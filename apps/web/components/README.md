# Components directory

Quick reference for what lives under `apps/web/components` and when to use each piece.

- Root helpers: `providers.tsx` wraps the app with theme + auth + upload providers; `theme-toggle.tsx` is a lightweight theme toggle for pages that don't use the shadcn button variant.
- `common/`: page chrome — `AppShell` (TopNav + Sidebar layout with collapsible desktop sidebar and mobile Sheet drawer), `Container` (max-width wrapper), `PageHeader` (title/description/actions row), `PanelCard` (collapsible card with localStorage-persisted open state), `SearchInput`, `Sidebar` (tags/bundles nav with loading states), `StatusChip` (worker state pill), `ThemeApplier` (reads `usePreferences` and applies theme classes to `<html>`), `ThemeToggle` (icon button variant), `TopNav` (global nav bar with user menu), `HelpDialog`, and `index.ts` barrel exports.
- `contexts/`: `AuthContext` fetches `/api/auth/me`, holds user/loading state, and exposes logout + `setUser`; `UploadContext` tracks client-side upload queue with helpers for progress/status updates.
- `bundles/`: `AddMediaDialog` lets users add library items to a bundle; `EditBundleModal` handles renaming and cover-image selection for a bundle.
- `dev/`: `DevPurgeButton` (development-only) bulk-deletes all visible media items; only rendered in `NODE_ENV=development`.
- `explorer/`: `ResultCard` renders a search/media tile with thumbnail fallback, status chip, and tags; `ResultGrid` lays results out in a responsive grid; `TagPane` lists available tags for filtering.
- `media/`: `MediaCard` shows a media item thumbnail with fallback and actions (download/rename/delete) in grid/list/compact modes; `MediaCardSkeleton` is its loading placeholder; `BulkActionBar` floats above the grid when items are selected; `BulkTagDialog` applies or removes tags across selected items; `BulkBundleDialog` adds selected items to a bundle; `MediaDetailSplit` is the two-column layout for the media detail page; `MediaInfoCard` surfaces actions (download/email/delete/regenerate thumbnail); `MediaMetadataCard` shows EXIF and file metadata with an inline title editor; `MediaPreviewCard` handles visual preview with fallback imagery; `MediaTextPanel` (entry point, re-exports from `text/`) renders extracted/OCR text states; `TagEditor` manages tags on a single media item; `UploadDialog` handles selecting and enqueuing uploads; `index.ts` is the barrel.
- `media/text/`: sub-components for the text extraction panel — `ExtractionControls` (re-run/cancel form with language and rotation options), `MediaTextContent` (virtualised text viewer with search highlight and copy), `TextEmptyState`, `TextErrorPanel`, `TextPanelHeader` (status/source/language badges), `TextRunningBanner`, `TextSegmentList`, `VirtualTextSegmentList`, `textPanel-utils.ts` (pure helpers: contrast chip logic, error classification, progress line).
- `reminders/`: `OverviewRemindersCard` renders the compact reminders widget on the overview page; `AddReminderDialog` and `EditReminderDialog` are controlled dialogs for creating and editing reminders.
- `ui/`: design-system primitives — `Badge`, `Button`, `Card`, `ConfirmPopover` (inline popover asking for confirmation before destructive actions), `Dialog`, `DropdownMenu`, `Input`, `Label`, `LogoutButton` (POSTs to `/api/auth/logout` then redirects), `ScrollArea`, `Sheet`, `Skeleton`, `TagChip`, `Toaster`.
